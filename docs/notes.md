# Technical Notes

 ## 1. Biggest Docker Challenge

One of the main challenges was making sure that the application worked correctly inside the Docker container. I needed to build the image, run the container, and make the application accessible through the browser.

I solved this by building the Docker image, running the container with the correct port mapping, and checking its status using `docker ps`. I also tested the application through `http://localhost:5000` to make sure it was working correctly.

 ## 2. Most Important Git/GitHub Lesson

The most important lesson I learned was how to manage a project using Git and GitHub. I learned how to initialize a repository, track files, create commits with meaningful messages, connect a local project to a remote repository, and push changes to GitHub.

This helped me understand how developers organize their work and keep track of project changes.
